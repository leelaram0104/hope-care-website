# Hope & Care Foundation Website
Frontend-only responsive website built with HTML, CSS and JavaScript.

## Pages
Home, About, Residents, Services, Donate, Volunteer, Contact, System Overview.

## Working features
- Responsive navigation and mobile menu
- Donation, volunteer and contact form validation
- Browser-local storage for demo submissions
- Live date/time, online status, device, browser and screen information
- Session page-view counter
- Local activity log
- Impact counters
- No fake organization-wide live statistics

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Note
This version does not process real payments or send emails because it has no backend. Forms demonstrate the complete frontend workflow and store demo data in the browser.
